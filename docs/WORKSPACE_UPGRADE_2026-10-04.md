# 간편 정리와 이름 일괄 변경 작업실

2026-10-04. 사용자 승인한 방향인 ‘간결한 메인 + 고급 작업 화면’을 구현했다. 무료/Pro 요금제와 화면을 분리하며 기존 무료 기능을 유료로 바꾸지 않는다.

## 사용자 흐름

- 최초 화면은 ‘자소 분리 정리’. 파일·폴더 추가 → 변경 결과 확인 → 선택한 이름 합치기 → 기존 명시 확인 순서다. NFC만 적용하며 이전 고급 규칙을 몰래 실행하지 않는다.
- ‘이름 일괄 변경’ 또는 기존 ⌘K 메뉴로 작업실을 연다. 큰 창은 규칙 편집/파일별 결과를 나란히, 좁은 창은 펼칠 수 있는 규칙 영역과 결과를 세로로 제공한다.
- 규칙 수정 시 이전 결과임을 표시한다. ‘파일 미리보기 갱신’으로 실제 입력 목록을 다시 검사한다. 미적용 규칙이 있으면 버튼뿐 아니라 Application 진입점에서도 Rename 계획을 차단한다. 자동 실시간 전체 목록 재평가로 변경한 것은 아니다.
- 간편 화면으로 복귀하면 활성 규칙은 NFC 전용으로 초기화하지만 작업실 초안은 현재 세션에 유지한다. 다시 들어오면 미리보기 갱신을 요구한다. 적용한 무료 규칙은 기존 lastFree 저장을 유지하며, 재시작 때 마지막 화면과 함께 복원한다. 적용하지 않은 초안을 재시작 후에도 저장한다고 주장하지 않는다.
- 설정 schema 1에 optional workbenchEnabled를 추가해 이전 설정을 호환한다. 경로·실행 확인·요금제 안전 경계를 바꾸지 않는다.
- Preview 갱신 중에는 규칙 편집을 잠근다. Pro 권한이 없어져 실제 규칙이 무료로 대체되면 기존 Pro 초안이 적용된 것처럼 표시하지 않는다.
- 카드·검색·필터·입력 위치·선택·기록·Undo·복구·텍스트 변환·NFD 선택·기타 도구를 유지한다. 추가 기능은 메뉴와 작업실로 정리했다. 화면 이름에는 Pro를 붙이지 않는다.

## 검증 범위

근거: `artifacts/development/workspace-upgrade/`.
- Debug arm64 빌드 및 ko/en/ja 리소스 검증.
- AppModel/문자표시/창배치/새 작업실/설정 손상·새 schema 관련 테스트.
- 실제 임시 파일에 접두사 규칙 적용 미리보기 및 Rename 계획 생성, 간편 복귀 후 원래 이름 미리보기 및 파일 내용 불변 확인. 사용자 파일 변경 없음.
- 작업실 상태는 revision으로 비교한다. 대형 CSV 전체를 UI redraw마다 비교하지 않는다.
- 간편/작업실/미적용 규칙 × 3언어 × 4테마 × 2크기 렌더. 사용자 화면 조작 없음.
