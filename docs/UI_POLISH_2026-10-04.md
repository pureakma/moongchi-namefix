# 설정·도구 UI 개선 (2026-10-04)

## 변경

- Apple HIG의 작업별 sheet, 기본 컨트롤, 명확한 계층과 점진적 정보 공개를 참고했다. 설정의 섹션 제목을 카드 밖으로 분리하고 가벼운 경계·일정한 여백을 적용했다. 자동 저장·네 테마·기존 설정 항목은 유지한다.
- 상단 출력 문자 형식 라벨을 제거하고 동작 이름 버튼과 접근성 이름이 있는 info 아이콘을 제공한다. 선택 sheet와 안내 sheet는 같은 라우터를 사용하며 중첩 sheet를 만들지 않는다.
- 이름 변경 규칙을 구성/미리 확인/예제·프리셋으로 묶었다. 텍스트 변환은 입력/변환 결과를 구분하고 Unicode 상세는 펼쳐 보기로 제공한다. 추가 도구는 감시/내보내기를 구분한다.
- NFC/NFD는 부가 표기로 유지하고 한국어는 자소 분리 합치기, 일본어는 분리 문자·탁점/반탁점, 영어는 separated characters로 목적을 설명한다. 시작 화면에 파일·폴더 드롭→검사→확인 흐름을 표시한다.
- 호환 자모로 별도 입력한 ㄱㅏ나 손상 인코딩을 복원한다고 주장하지 않는다. 파일 변경은 기존 Preview/명시 확인 경로를 그대로 사용한다.

Release·Store 실거래·서명·공증·배포는 실행하지 않는다. 기존 build3 후보는 이번 UI 변경 전 산출물이며 수정본은 별도의 Debug 앱으로 제공한다. 과거 출시 후보 소스 fingerprint는 현재 UI 증거로 사용하지 않는다.
