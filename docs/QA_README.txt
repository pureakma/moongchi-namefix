Moongchi NameFix 1.0.0 (1) — Apple Silicon arm64 / macOS 14+

로컬 개발자 QA 패키지입니다. Developer ID 서명 및 공증을 완료한 공개 배포본이 아닙니다.
arm64 실행용 ad-hoc 서명만 적용했습니다. Intel/Windows 대상은 없습니다.

실행: 이 폴더의 Moongchi NameFix.app을 Finder에서 여세요.
DMG: Applications 링크로 직접 드래그해 복사할 수 있습니다. 자동 설치하지 않습니다.
Gatekeeper를 비활성화하거나 검역 속성을 제거하는 절차는 제공하지 않습니다.
외부 배포는 Developer ID와 공증 완료 후 가능합니다.

처음에는 전용 복사본/fixture로만 확인하세요.
파일·폴더 추가 → 현재/변경 후 이름 검토 → N개 이름 수정 → 확인.
Undo도 작업 기록에서 미리보기 후 확인합니다. 자동으로 복구하지 않습니다.
동일 항목을 다른 프로그램에서 동시에 이동/교체하지 마세요.

지원: 로컬 APFS. 링크·앱/package·확인되지 않은 볼륨·알려진 클라우드 위치는 보호합니다.
macOS 14 실기, 실제 Finder 드롭·Services, 외부 볼륨, 접근성은 별도 수동 QA가 필요합니다.
설정/기록은 ~/Library/Application Support/Moongchi/NameFix 에 저장됩니다.
앱을 제거해도 사용자 파일이나 작업 기록은 자동 삭제하지 않습니다.
